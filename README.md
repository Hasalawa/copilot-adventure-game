# Moonlit Map Adventure

A simple command-line choose-your-own-adventure game written in Python. You explore crossroads, forests, towers, rivers, and hidden chambers by choosing numbered options. Your decisions lead to multiple possible endings, and you can replay the story to discover different paths.

## How to Run

Make sure Python 3 is installed, then run:

```bash
python3 adventure.py
```

On systems where Python 3 is invoked as `python`, use:

```bash
python adventure.py
```

Enter the number for the option you want to choose at each scene. When the adventure ends, enter `y` to play again or any other response to quit.

## Features

- Multiple branching scenes
- Several unique endings
- Input validation for invalid choices
- Replay support
- No external dependencies
