# Security Policy

## Supported Versions

Moonlit Map Adventure is a small command-line project. Security fixes are
currently provided for the latest version on the default branch.

| Version | Supported |
| ------- | --------- |
| Latest default branch | Yes |
| Older versions | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for this repository, if
available. If private reporting is unavailable, contact the repository
maintainers privately through the contact options provided by the repository
owner.

Include the following information in your report:

- A description of the vulnerability and its potential impact.
- Steps or a minimal example needed to reproduce it.
- The affected file, function, or version.
- Any suggested mitigation, if known.

Please avoid including secrets, personal information, or unnecessary
production data in a report.

## Response Process

Maintainers will acknowledge reports as soon as practical, investigate the
issue, and coordinate a fix or mitigation when appropriate. Please allow time
for the issue to be reviewed before publicly disclosing details.

Once a fix is available, maintainers may publish a summary and credit the
reporter if they have permission to do so.
